# Product creator module

Модуль добавляет безопасное создание товаров через Telegram.

1. Получите из Playerok ID категории и ID типа получения.
2. Отправьте `/product_schema <ID_категории> <ID_типа_получения>` — бот подготовит JSON-шаблон с атрибутами и обязательными полями.
3. Отправьте `/product_create`, затем вставьте заполненный JSON отдельным сообщением.
4. Подтвердите создание черновика.
5. При необходимости выберите приоритет и ещё раз подтвердите публикацию.

Товар никогда не публикуется автоматически: сначала создаётся черновик, затем требуется отдельное подтверждение публикации.

Команды доступны только пользователям, указанным в `telegram.bot.signed_users` основного конфига.
